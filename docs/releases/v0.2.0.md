# Margin · 页边 v0.2.0

**更完整的 Markdown 阅读与审阅。 / Richer Markdown, precise review.**

## Highlights / 本次更新

- Markdown 表格与对齐、嵌套列表、任务清单、多层引用和提示块。
- 引用／自动链接、章节及相对文档跳转、本地图片、脚注、公式和文档属性。
- 常用 HTML 安全渲染：折叠详情、合并单元格、上下标和文字格式。
- 表格、HTML 文本、转义符与实体的准确源码映射，继续支持选区批注与修订。
- 保留 BOM、换行和审阅历史；审阅包导入后恢复本地图片、批注与修订。
- 桌面版点击外部链接后交给系统浏览器或邮件应用。
- 新增 Markdown 支持说明、浅色／深色／移动端截图与自动化回归。

Tables, nested/task lists, links, local images, footnotes, math, callouts and common
HTML now render as structured content while retaining precise source-linked review.

## Scope / 边界

- 编辑仍基于源码；任务复选框只读。代码块暂不语法着色；不渲染 Mermaid / MDX。
- 远程图片不自动加载；HTML 脚本、事件、任意样式与嵌入媒体不执行。
- LaTeX 阅读视图不是排版 PDF 编辑器。非 UTF-8 文件只读。
- 审阅包保留完整历史，压缩前后均限 32 MiB；同 ID 分支不自动合并。
- 本次提供 macOS / Windows 桌面包；Linux 可使用本地浏览器版。
