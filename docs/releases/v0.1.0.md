# Margin · 页边 v0.1.0

**让想法，留在页边。 / A little room for thought.**

Margin 的首个独立版本：本地阅读、批注和修订 Markdown 与 LaTeX，保留原始源码，
把完整审阅历史带到下一轮。无需账号、模型或 API Key。

The first independent Margin release: a local workspace for reading, annotating
and revising Markdown and LaTeX, with portable, complete review history.

## Highlights / 本次发布

- 全新紫色「书页＋页边批注」图标，原生 macOS / Windows 多分辨率资源。
- 暖白阅读纸面、精细导航与审阅侧栏，浅色／深色主题和移动端布局。
- Markdown / LaTeX 同等支持；选区、段落与全文批注、回复和状态管理。
- 源码编辑、修改理由、关联批注、版本恢复、原稿与源码级差异视图。
- `.marginreview` / ZIP 审阅包，恢复稳定 ID、正文、资源、批注、修订与事件。
- 桌面首页、原生打开／导出、拖放、最近项目、未保存提醒与持久化工作区。
- 独立命名空间与旧数据迁移支持，重写的中英文 README 和完整文档。
- No built-in AI execution. Model-task routes return 410.

## Downloads / 下载

| Platform | Asset |
| --- | --- |
| macOS Apple Silicon | `Margin-0.1.0-mac-arm64.dmg` or `.zip` |
| macOS Intel | `Margin-0.1.0-mac-x64.dmg` or `.zip` |
| Windows x64 | `Margin-0.1.0-win-x64.exe` |

macOS：将 Margin 拖入「应用程序」。Windows：运行当前用户安装程序。
安装版内置 Node；LaTeX 工具不随应用附带。`SHA256SUMS.txt` 提供全部五个安装产物的校验和。

**Unsigned builds; macOS is not notarized. / 安装包未签名，macOS 未公证。**
系统可能显示未识别开发者提示。没有自动更新；后续版本从 GitHub Releases 下载。

## Scope / 已知边界

- Markdown 并非完整 CommonMark/HTML 渲染器；LaTeX 阅读视图并非排版 PDF 编辑器。
- 非 UTF-8 文件只读；审阅包压缩前后均限制 32 MiB。
- 审阅包包含历史版本与已删除批注。重复 ID 导入被拒绝，不自动合并分支。
- Linux 可运行本地浏览器版；本次不提供 Linux 桌面安装包。
