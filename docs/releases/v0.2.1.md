# Margin · 页边 v0.2.1

**更兼容的公式，更准确的表格与选区。 / Better math, tables and selection actions.**

## Highlights / 本次更新

- Markdown 公式使用本地 MathJax 3，向 Typora 常用数学语法对齐：AMS 环境、矩阵、
  分段函数、化学式、physics 命令、文档内宏及前向公式引用。
- 支持灵活的显示公式分隔符、独立 equation / align 等环境和 `math` 围栏。
- 修复表格内公式中的 `|`、`\|` 被错误分列或丢失反斜杠的问题，保留精确源码映射。
- 无法渲染的公式保留源码并显示错误提示，仍可选中批注与修订。
- 取消或折叠选区、点击别处、按 Esc 后隐藏选区按钮；重新选中正文后再次显示。
- MathJax 完全本地运行，无 CDN 或远程扩展下载；LaTeX 阅读视图继续使用 KaTeX。

Markdown math now uses local MathJax with AMS, chemistry, physics, document-scoped
macros and equation references. Math pipes stay inside table cells. Selection
actions disappear when the selection is cleared and return on reselection.

## Verification / 验证

- 本地 Node 22：149 项测试通过；Markdown Chromium 回归、双格式审阅及 Electron smoke 通过。
- 三个平台原生构建分别验证开发版和打包应用；MathJax 公式在打开、审阅包导入及
  应用重启后均纳入桌面检查。Windows smoke 不包含 NSIS 安装向导交互。
- 构建与附件校验结果将在正式发布时补充到本发布页。

## Scope / 边界

- MathJax 不是完整 LaTeX 编译器，不支持任意宏包或 Typora 的全部可选扩展。
- 编辑仍基于源码；任务复选框只读；不渲染 Mermaid / MDX 或远程图片。
- HTML 和公式输出均经过允许列表处理，审阅历史、编码和换行保持原有机制。
- 本次提供 macOS / Windows 桌面包；Linux 可使用本地浏览器版。
