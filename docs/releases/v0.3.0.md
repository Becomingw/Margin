# Margin · 页边 v0.3.0

正文直接编辑、外部 Agent MCP，以及更顺手的论文审阅。

## 本次更新

- **Plate / Slate Markdown 编辑器**：点击「直接编辑正文」，直接输入、设置格式、编辑
  链接与表格，支持撤销／重做。显式保存后记录为修订；未修改块保留原始源码。
- **外部 Agent MCP**：7 个工具支持读取 Markdown / LaTeX、查询历史、批注、回复和
  修改建议。支持 HTTP 与 stdio；桌面端通过顶部 MCP 导出连接配置。
- **人工确认修改**：建议先显示差异，采纳后才写入正文；保留 AI 来源、完整历史、
  撤销能力及 ZIP 交接记录。过期建议和冲突保存会被拒绝，未保存草稿得到保留。
- **审阅体验与稳定性**：侧栏折叠、批注搜索、上一条／下一条定位、固定筛选栏；
  优化高亮范围查询，修复迟到响应覆盖或跳回旧文档的问题。

复杂公式、HTML、图片、脚注等暂时通过保真的源码块编辑。Markdown 公式继续使用
本地 MathJax；结构性编辑可能规范化受影响块的 Markdown 写法。

## English summary

Margin 0.3.0 adds a locally bundled React / Plate / Slate Markdown editor and
external-agent MCP over HTTP or stdio. Authors explicitly save drafts and accept
agent suggestions; unchanged source blocks, review provenance and portable history
are preserved. Review search/navigation and asynchronous document handling are improved.

## Verification

Local Windows checks: 156 passing Node cases, 5 existing platform/legacy skips,
portable smoke, Chromium editor/review/Markdown regressions and real Electron
save/restore, MCP, review-package and restart checks. The release workflow runs
tests and validates the packaged executable on each target platform before upload.
